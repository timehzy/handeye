# handeye N1–N4 实施计划（双端设备脚手架迁移）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 insedit e2e 脚手架中「与业务零耦合」的设备侧资产泛化迁移进 handeye：双端 build/install、隧道 setup、冷启动进态注入（Android deeplink / iOS 配置注入）、批跑总控 `run.sh`、素材两级兜底与接入文档，使接入者在 Android / iOS 真机上「构建 → 安装 → 冷启动进态 → 建隧道 → 批跑」一条龙，且每个项目特有的决策点都可配置、可发现。

**Architecture:** 顶层新增 `scripts/`（runner 侧脚手架，跨 demo 通用）：公共层 `_common.sh` 提供三级配置读取（环境变量 → `handeye.local.sh` → `handeye.example.sh` 默认值）与生命周期钩子；`run.sh` 为总控（拉 bootstrap plan → 按 (page, source) 分组 → 逐组 build/install + bootstrap 进态 + setup 隧道 → 批跑 → 汇总）；demo 专属入口 `run_demo_e2e.sh` 降级为薄封装。协议与编排器不动（首期已具备 `--print-bootstrap-plan`、FixtureCatalog、ArtifactDumper）。

**Tech Stack:** bash 3.2+（macOS 出厂版本为兼容下限，**禁止** mapfile / 关联数组等 bash 4 特性）、curl、jq、adb（Android SDK platform-tools）、libimobiledevice（idevice_id / iproxy / afcclient）、Xcode（xcodebuild / devicectl）。Kotlin 侧仅 demo App 接收端小改。

**Spec:** `docs/superpowers/specs/2026-09-29-handeye-harness-scripts-migration.md`（本计划唯一需求源）

**内部源仓参考路径：** `/Users/insta360/Workspace/INSAIWorkSpace/insedit`（下称 `<insedit>`）。平移类任务从这里复制文件，不要改动源仓。

# require_tools "adb:Android SDK platform-tools" "jq:brew install jq" ...
require_tools() {
  local missing=0 spec tool hint
  for spec in "$@"; do
    tool="${spec%%:*}"; hint="${spec#*:}"
    command -v "$tool" >/dev/null 2>&1 || { printf '缺少 %s（%s）\n' "$tool" "$hint" >&2; missing=1; }
  done
  [ "$missing" -eq 0 ] || exit 4
}

共享设备助手（从 `demo-android/scripts/run_demo_e2e.sh` 的现成实现迁移）：

```bash
# 等 App 进程出现，返回 pid（超时 exit 2）
wait_app_pid() { # $1=adb 前缀数组名无法用 bash3.2 —— 用全局 ADB 变量拼接
  local pid="" i
  for i in $(seq 1 40); do
    pid="$($ADB shell pidof "$APP_ID" 2>/dev/null | tr -d '\r' || true)"
    [ -n "$pid" ] && { printf '%s' "$pid"; return 0; }
    sleep 0.5
  done
  return 1
}

# 从 /proc/<pid>/net/tcp{,6} 反查 debug server 端口：只取 loopback LISTEN(0A) 候选，
# 逐个 adb forward 后用 /health 实测，第一个应答者为准。（整网络命名空间可见，必须实测。）
discover_debug_server_port() { # $1=pid，stdout=端口；找不到返回 1
  local pid="$1" hex dec
  local candidates
  candidates="$($ADB shell "cat /proc/$pid/net/tcp /proc/$pid/net/tcp6 2>/dev/null" \
    | awk '$4=="0A"{split($2,a,":");if(a[1]=="0100007F"||a[1]=="0000000000000000FFFF00000100007F")print a[2]}' \
    | tr -d '\r' | sort -u)"
  while IFS= read -r hex; do
    [ -z "$hex" ] && continue
    dec=$((16#$hex)); [ "$dec" -gt 1024 ] || continue
    $ADB forward "tcp:$dec" "tcp:$dec" >/dev/null 2>&1 || continue
    if curl -sf -m 2 "http://127.0.0.1:$dec/health" >/dev/null 2>&1; then printf '%s' "$dec"; return 0; fi
    $ADB forward --remove "tcp:$dec" >/dev/null 2>&1 || true
  done <<EOF
$candidates
EOF
  return 1
}

# probe /health 直到就绪（默认 15s）：就绪标准 = HTTP 200 且 .ok=true
probe_health() { # $1=baseUrl
  local i
  for i in $(seq 1 30); do
    curl -sf -m 2 "$1/health" 2>/dev/null | grep -q '"ok":true' && return 0
    sleep 0.5
  done
  return 1
}
```
